# 知识蒸馏

知识蒸馏是把大型复杂模型（“Teacher”）的智能迁移到更小、更高效模型（“Student”）中的过程。这是今天的小型开放权重模型能够以远超其参数量的能力表现的秘诀。

## Teacher–Student 范式

小模型（例如 Llama 4 8B、Gemini 3.1 Flash、Claude Haiku 4.5）并不只是用原始网页数据训练。它们使用更大型模型（例如 GPT-5.5、Claude Opus 4.7 或 Llama 4 405B）生成或整理的**合成数据**进行训练。

| 模型 | 角色 | 智能来源 |
|-------|------|---------------------|
| **Teacher** | 大型（100B+ 参数） | 在 50T+ token 上预训练 |
| **Student** | 小型（1B–8B 参数） | Teacher 过滤后的逻辑/输出 |

---

## 蒸馏如何工作

### 1. 硬标签蒸馏

Student 从 Teacher 的最终预测中学习（例如问题的答案）。

### 2. 软标签蒸馏（温度缩放）

Student 从 Teacher 的**概率分布**（Logits）中学习。这种信息丰富得多，因为它不仅告诉 Student 正确答案，还告诉它哪些错误答案“几乎”正确。

```python
# 蒸馏损失（KL 散度）：
Loss = KL_Div(Teacher_Logits / T, Student_Logits / T)
```
*其中 T 是温度（通常为 2.0–5.0）。*

## 特征蒸馏与输出蒸馏

### 输出蒸馏（标准方式）

Student 匹配 Teacher 的文本回答。
- **优点：**可以通过 API 容易实现。
- **缺点：**只学习行为的表层模式。

### 特征/隐藏状态蒸馏

Student 匹配 Teacher 的内部**隐藏状态**（向量表示）。
- **要求：**需要能访问 Teacher 的权重（开放权重）。
- **优点：**Student 学到 Teacher 的“内部概念地图”，带来更深的推理能力。

## 从证明进行自蒸馏（SDP）

**推理上的突破。**
o1、DeepSeek-R1 和 Claude Opus 4.7 等模型使用 SDP，在没有新增人工数据的情况下获得提升。

1. **生成：**模型针对困难数学/代码问题生成 100 个可能的解决方案。
2. **验证：**基于规则的系统（编译器/计算器）找出 1 个正确方案。
3. **蒸馏：**在促成该正确方案的“思维链”（CoT）上对模型做微调。

**结果：**模型只保留高质量推理路径，从而“蒸馏自己”。

## 量化感知蒸馏

标准量化（例如从 16-bit 到 4-bit）会造成少量精度下降。
**修复方法：**在量化过程中使用知识蒸馏。16-bit 模型作为 Teacher，引导 4-bit 模型最小化误差。这就是现代 4-bit 模型能够匹配 16-bit 性能的方式。

## 面试问题

### Q：为什么蒸馏出的 8B 模型比在相同 token 上从头训练的 8B 模型更好？

**强回答：**
在原始网页数据上从头训练（预训练）时，数据有噪声，模型要消耗大量容量来学习处理这些噪声。而蒸馏模型是在“净化后的”课程上训练的。Teacher 充当高质量过滤器，提供结构化逻辑、清晰解释和更干净的语言分布。本质上，Teacher 通过 logits 分布提供“提示”，准确告诉 Student 哪些语言特征最值得学习。

### Q：使用 GPT-4o 作为 Teacher 蒸馏 Llama Student 有哪些风险？

**强回答：**
1. **模型坍缩：**如果 Student 只看到 Teacher 的输出，它可能失去创造性或多样知识的“长尾”，只学习 Teacher 狭窄的偏见。
2. **许可证违规：**大多数专有模型（OpenAI、Anthropic）都有禁止使用其输出训练“竞争模型”的条款。对于使用 API 输出蒸馏自有模型的企业，这是主要法律风险。
3. **语言模仿：**Student 可能学会像 Teacher 一样听起来很自信，却没有相同的逻辑深度，导致自信但错误的幻觉。
