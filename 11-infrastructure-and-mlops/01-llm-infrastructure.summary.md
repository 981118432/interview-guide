# LLM 基础设施：中文概要

本章介绍生产级 LLM 系统的部署、服务、扩展、成本、监控和灾难恢复。核心选择是 API 还是自托管：API 上线快、运维少，适合低到中等流量和快速试错；自托管能控制数据、延迟和模型，适合严格合规、大流量和定制场景。

重点掌握模型路由、多模型回退、GPU/队列扩展、成本归因、预算告警、P99 监控和优雅降级。2026 年的容量规划不应只看 FLOPS，还要看每个加速器的内存、供应商锁定和多供应商故障相关性。

面试中可以用“多供应商 + 路由 + 缓存 + 队列 + 采样评测 + 自动回退”的组合回答大规模 LLM 基础设施设计题，并明确说明自托管需要承担 GPU、运维和模型升级成本。
