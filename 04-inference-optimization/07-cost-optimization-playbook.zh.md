# 成本优化实战手册

AI 成本已经不再是“魔法”：它可测量、可预测，也高度可优化。随着 API 价格在过去一年下降 30～60%，成本杠杆现在主要在于*路由*和*缓存*，而不只是选择更便宜的供应商。本章介绍如何在不牺牲质量的情况下把推理成本降低 10 倍。

## AI 的单位经济学

我们用 **Tokens per Dollar（每美元 Token 数）**衡量成功。

| 组件 | 成本驱动因素 | 优化方式 |
|------|--------------|----------|
| **计算** | GPU 时间（$/hr） | 提高利用率（批处理）。 |
| **VRAM** | KV Cache 大小 | GQA、量化。 |
| **网络** | Payload 大小 | 压缩、本地服务。 |
| **API** | 按 Token 定价 | 缓存、模型选择。 |

## 模型级联（效率层级）

最有效的省钱策略是使用**能够完成任务的最便宜模型**。

**级联模式：**
1. **分类器**：一个极小的模型（0.5B）判断查询复杂度（$0.00）。
2. **Tier 1（SLM）**：90% 的查询（问候、简单问答）交给 8B 模型（$）。
3. **Tier 2（前沿模型）**：9% 的查询（复杂推理）交给 405B/Claude Sonnet 4.6/GPT-5.5/Gemini 3.1 Pro 级别的模型（$$$）。
4. **Tier 3（推理模型）**：1% 的查询（专家级问题）交给 Claude Opus 4.7 或开启扩展思考的 GPT-5.5 等思考模型（$$$$$）。

**最终结果**：相比把所有流量都发给 Tier 2，成本降低 80%。

## 生产环境中的小型语言模型（SLM）

3B～8B 模型（Llama 4 8B、Gemini 3.1 Flash、Claude Haiku 4.5）现在在大多数基准上已经能够匹敌甚至超过 2023 年最初的 GPT-4。
- **使用场景**：实体抽取、情感分析、简单 RAG。
- **成本**：运行成本比前沿模型低 100 倍。
- **延迟**：响应时间 < 100ms。

## Spot 实例策略

对于非实时工作负载（批处理、数据抽取），使用 **GPU Spot 实例**（AWS Spot、Azure Spot、Lambda Labs）。

- **风险**：GPU 可能提前 30 秒通知后被回收。
- **缓解**：**在线 KV Cache 迁移**。服务框架可以在收到“回收信号”后立即把正在进行的请求的 KV Cache 流式传输到另一节点，确保不丢失已完成的工作。

## “Token 税”优化

- **系统 Prompt 缓存**：把常见前缀硬编码，以获得 90% 的折扣。
- **输出截断**：严格限制 `max_tokens`。
- **负向 Prompt**：“不要冗长”可以节省约 15% 的输出 Token（以及相应成本）。

## 面试问题

### Q：如何向 CFO 证明 AI 系统的成本合理？

**强回答：**

我关注的是**效率带来的 ROI**。首先，我会实施“模型级联”，确保 90% 的流量由每百万 Token 成本低于一美分的模型处理。其次，我会实施“语义缓存”，避免同一个答案付费两次。第三，我会建立“推理配额”和“成本分摊模型”，让每个业务部门对自己的用量负责。把 AI 当作一种带有分级价格的“商品资源”，我们就能从“无上限的实验”转向“可预测的运营支出（OpEx）”模式。

### Q：什么时候自托管的单 GPU 集群会比 API 更便宜？

**强回答：**

“交叉点”通常出现在**持续的高吞吐量**场景。如果应用有 5～10 RPS 的基线流量并且 7×24 运行，H100 预留实例的固定成本会低于 API 的可变 Token 成本。不过，如果流量“尖峰明显”或主要集中在工作时间，API 通常更便宜，因为它允许你在非高峰期“为沉默付费”。对于大多数企业，70B 级模型的盈亏平衡点约为每月 5 亿 Token。
