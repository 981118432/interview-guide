# 《Microsoft Agent Framework、CrewAI 与 Agent SDK 版图》中文概要

理解 CrewAI Process/Flows、Microsoft Agent Framework 对 AutoGen 与 Semantic Kernel 的合并，以及 Claude Agent SDK、OpenAI Agents SDK/AgentKit/Apps SDK 和 Google ADK 的定位。面试重点是根据业务流程速度、图级控制、企业 .NET/Python、模型供应商和跨 Agent 通信需求进行选择，并用交接、终止条件、最大轮数、评论 Agent 和 Token 速度控制避免无限循环。
