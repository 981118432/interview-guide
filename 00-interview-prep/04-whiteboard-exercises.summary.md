# 《AI 系统设计白板练习》中文概要

这篇资料提供 9 个场景，训练从需求澄清到可靠性设计的完整面试动作。

## 优先练习

对你的目标岗位，优先练习企业 RAG、评测流水线、长时间 Agent、多租户平台和文档处理。它们能直接连接 AliceFeed 的 RAG、上下文压缩、RAGAS、Langfuse 和 Tool Calling 经历。

## 白板固定结构

```text
需求与假设 → 指标 → 初始架构 → 关键路径
→ 评测/观测 → 故障/安全/成本 → 总结权衡
```

## 一句话总结

白板面试不是比谁画的组件多，而是看谁能设计一条可解释、可评测、可恢复的端到端数据流。
