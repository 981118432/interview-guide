# 《AI 系统设计面试题库》中文概要

## 内容范围

本章覆盖 128 道 AI 系统设计问题和 5 个综合设计场景，主题包括：

- RAG、分块、混合检索、重排序和多租户隔离
- Agent、ReAct、Tool Calling、MCP、Flow Engineering 和 Multi-agent
- 模型选择、推理模型、Embedding、KV Cache、批处理和量化
- LLM 评测、RAGAS、幻觉、可观测性、CI/CD 和成本控制
- 向量数据库、DSPy、反馈闭环、Prompt 版本和安全
- 客服、文档处理、企业搜索、代码助手和内容审核系统设计

## 面试答题主线

所有题目都可以沿着这条主线组织：

```text
澄清场景 → 明确指标 → 画出数据流 → 深挖关键路径
→ 讨论评测与可观测性 → 补充可靠性、安全和成本
```

## 最应该掌握的知识

### RAG

能够完整解释数据接入、解析、分块、Embedding、向量检索、BM25、RRF、重排序、上下文组装、LLM 生成和引用。要知道什么时候用 RAG，什么时候用微调或长上下文。

### Agent

能够区分 Workflow 和 Agent，解释 ReAct 循环、Tool Calling、MCP、状态管理、Checkpoint、循环限制、人工升级和多 Agent 的适用边界。

### 评测

能够从检索、生成和端到端三个层面设计评测，并把 RAGAS、LLM-as-Judge、人工抽检、用户反馈和生产回归结合起来。

### 生产化

必须主动覆盖延迟、吞吐、成本、限流、配额、Fallback、模型版本、Prompt 版本、可观测性、故障恢复、权限隔离和安全。

## 对你的重点关联

- RRF、BM25 和向量检索可以结合金融产品知识查询说明
- Tool Calling、循环限制和 Flow Engineering 可以结合 AliceFeed Copilot 说明
- 上下文压缩可以用于回答长对话和 Agent 状态管理
- RAGAS、测评集和自动化回归可以用于回答 LLM 应用评测
- Langfuse 可以用于回答 Agent Trace、Prompt 版本和可观测性
- Java 后端经验可以用于说明网关、限流、缓存、队列、数据一致性和故障恢复

## 学习顺序

1. 先掌握 Q1-Q10 的 RAG 基础架构
2. 再学习 Q11-Q17 的 Agent 和 MCP
3. 用 Q18-Q49 补齐模型、推理、评测、生产和安全基础
4. 用 Q50-Q128 训练前沿场景和追问能力
5. 最后练习 5 个综合系统设计场景

## 一句话总结

这不是一份单纯的模型知识题库，而是一套训练“如何把 AI 能力设计成可评测、可观测、可控制、可上线系统”的面试材料。
