# AI 系统设计面试准备

这组资料面向已经具备生产开发经验、希望进入资深或 Staff AI 工程岗位的工程师。它覆盖 128 道系统设计题、答题框架、常见陷阱、白板练习、行为面试、岗位趋势和 FAQ。

## 开始之前

资料假设读者已经了解 token、上下文窗口、Embedding 和 RAG 等基础概念。如果这些概念还不熟悉，应先学习基础章节，再进行面试训练。没有基础知识时直接背面试答案，容易形成听起来流畅但经不起追问的回答。

## 推荐阅读顺序

```text
题库 → 答题框架 → 常见陷阱 → 白板练习 → 行为面试 → 岗位趋势 → FAQ
```

如果只有两周，优先题库和答题框架；只有一周，优先答题框架和白板练习；只有三天，先看常见陷阱、FAQ 和三道白板题。

## 按岗位选择路径

- **AI Engineer：** Q1-Q49、答题框架和白板练习
- **Staff/Principal：** Q50-Q128、STAR-L、评测、记忆和可靠性
- **Applied Scientist：** 模型选择、评测和推理优化
- **PM/TPM：** 常见陷阱、岗位趋势、答题框架和产品权衡

## 配套资源

可以结合系统设计指南其他章节、岗位迁移指南、课程、术语表和案例研究使用。题库用于建立覆盖面，答题框架用于组织表达，白板练习用于模拟真实面试。

## 关键要点

不要只背模型名称和组件清单。高级候选人需要说明需求、指标、数据流、关键权衡、评测、可观测性、故障恢复、成本、安全和自己的真实负责范围。建议每月复习一次，因为模型、价格、协议和招聘要求会持续变化。
