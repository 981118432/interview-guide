# AI 工程、RAG 与 Agent 常见问题

## 通用问题

### 什么是 AI Engineer？

AI Engineer 负责把模型能力接入真实产品，包括数据处理、Prompt、RAG、Agent、工具、评测、部署、监控、安全和成本。重点是应用工程和生产化，不等同于训练基础模型。

### AI Engineer 和 ML Engineer 有什么区别？

ML Engineer 更偏数据、训练、特征、模型部署和机器学习平台；AI Engineer 更偏 LLM 应用、检索、Agent、工具编排、评测和产品集成。两者边界会随团队变化。

### 如何成为 AI Engineer？

先打好后端、Python、数据和 API 基础，再学习 LLM、RAG、Agent、评测、可观测性、部署和安全。通过一个真实可运行的项目证明质量、成本和故障处理能力。

### 应该学习哪种编程语言？

Python 适合模型、数据和 Agent 生态；Java、Go 或 TypeScript 适合后端服务、平台和企业集成。优先使用团队生产栈，并理解跨语言服务边界。

### AI 工程是好职业吗？

机会较多，但岗位要求快速变化。长期竞争力来自解决业务问题、上线和运营 AI 系统的能力，而不是只会某个热门框架。

## RAG

### 什么是 RAG？

RAG 在生成前从外部知识库检索相关内容，再把内容放入上下文，让模型基于较新的、可追溯的资料回答。

### RAG 如何工作？

离线侧解析、分块、生成 Embedding 并建立索引；在线侧接收查询、改写、混合检索、重排序、组装上下文、调用 LLM 并返回引用。

### 长上下文出现后 RAG 过时了吗？

没有。RAG 仍然提供选择性上下文、权限过滤、数据新鲜度、来源引用和成本控制。长上下文可以减少部分检索需求，但也带来成本、中间丢失和数据隔离问题。

### RAG 和微调有什么区别？

RAG 改变模型回答时可访问的知识，适合频繁更新和需要引用的内容；微调改变行为、风格、格式或任务模式，适合稳定且高质量的训练样本。两者可以组合。

### 最好的向量数据库是什么？

没有通用答案。比较数据规模、过滤、多租户、延迟、召回、备份、运维、成本和团队经验。用真实数据和查询做基准。

### 什么是 Contextual Retrieval？

在分块前或分块时为文本块补充文档、章节和主题上下文，使孤立文本块包含更多语义信息，再进行检索。

### 什么是 Hybrid Search？

同时使用稠密向量检索和 BM25 等稀疏检索，再用 RRF 或加权方式合并，兼顾同义表达和精确关键词。

### 什么是 GraphRAG？

从文档中抽取实体和关系构建知识图谱，查询时结合图遍历与文本检索。它适合关系推理和跨文档连接明显的场景，但构建和维护成本更高。

### RAG 最佳分块大小是多少？

没有固定答案。根据文档结构、查询粒度、模型上下文和评测结果选择，通常需要结合递归分块、重叠、父子块和语义分块实验。

## Agent

### 什么是 AI Agent？

Agent 是以目标为导向，能根据观察结果选择步骤、调用工具并维护状态的模型驱动系统。它通常包含模型、工具、状态、编排、限制和评测。

### Agent 和 Chatbot 有什么区别？

Chatbot 主要围绕对话生成回答；Agent 可以规划、调用工具、读取外部数据、执行动作和循环验证。Agent 也可能只是聊天系统中的一个局部组件。

### 什么是 MCP？

MCP 是连接 LLM 应用与工具、资源、Prompt 的协议标准。它降低集成成本，但 Server 权限、身份、供应链和工具审计仍需单独设计。

### 最好的 Agent 框架是什么？

取决于状态管理、图编排、工具生态、调试、持久化和团队技术栈。先理解 Workflow、状态机、ReAct 和可靠性，再选择框架；不要让框架隐藏关键控制流。

### 什么是 Agentic RAG？

Agent 根据任务动态决定查询改写、检索次数、工具和验证步骤。它比固定 RAG 灵活，但延迟、成本、循环和安全风险更高。

### Computer-use Agent 如何工作？

模型读取屏幕或页面状态，选择点击、输入、滚动等动作，再观察结果并继续。生产环境需要沙箱、网络策略、动作确认、审计和失败暂停。

### 什么是 Context Engineering？

它是系统化设计模型每次调用所见信息的过程，包括 Prompt、工具、检索结果、历史、记忆、状态、压缩、排序和权限，而不只是写提示词。

### 什么是 Agent Skills？

Skill 是可复用的任务能力描述、执行步骤、输入输出和安全边界。它不同于底层 MCP Tool，也不同于改变模型权重的 Fine-tuning。

## 模型

### 当前最好的 LLM 是哪个？

没有脱离任务的最佳模型。根据质量、推理、上下文、工具调用、延迟、成本、隐私、可用性和评测结果选择，并保留路由与 Fallback。

### Claude、GPT、Gemini、DeepSeek 的成本是多少？

价格经常变化，应查看官方价格页。成本还包括输入/输出 token、缓存、重试、Embedding、重排序、GPU 和运维，不能只比较单价。

### Claude Opus 和 Sonnet 有什么区别？

通常是能力、速度和价格的不同定位，但具体能力会随版本变化。使用固定任务集比较，不要把型号名称当成永久结论。

### 应该使用开源模型吗？

在需要数据控制、成本优化、定制或离线部署时考虑开源模型；同时承担 GPU、运维、升级、质量和许可证责任。可用多模型架构降低风险。

### 什么是 Prompt Caching？

对重复的 Prompt 前缀或上下文复用计算，减少成本和延迟。要保持前缀稳定，并处理版本、权限、TTL 和失效。

## 评测

### 如何评估 LLM？

定义任务级数据集和 rubric，结合规则指标、LLM-as-Judge、人工评测、用户反馈、任务完成率、延迟和成本。持续评测而不是只做一次 Demo 测试。

### 什么是 LLM-as-Judge？

使用一个 LLM 按明确标准评价另一个模型的输出。它适合扩大评测规模，但会有位置偏差、长度偏差、模型偏好和评分不稳定，需要人工校准。

### 最好的 LLM 可观测工具是什么？

选择能记录 Trace、Prompt、模型、工具、检索、token、成本、反馈和评测的工具。Langfuse、LangSmith 等只是工具，关键是指标设计和数据治理。

### 什么是 RAGAS？

RAGAS 是评估 RAG 检索与生成质量的一组指标和方法，包括 Faithfulness、Answer Relevance、Context Precision 和 Context Recall。

### 如何检测生产中的模型漂移？

监控输入分布、检索结果、输出质量、拒答、幻觉、用户反馈、延迟和成本，并与固定基线和评测集比较。发现漂移后做切片分析、回滚或重新评测。

## 推理

### 什么是 vLLM？

vLLM 是用于高吞吐 LLM 推理服务的开源框架，常见能力包括 Paged Attention、Continuous Batching、OpenAI 兼容 API 和多模型部署。

### vLLM 和 SGLang 有什么区别？

两者都面向高效推理，但对模型执行、结构化生成、缓存和编排的优化重点不同。用目标模型、硬件和真实请求基准测试选择。

### 什么是 TensorRT-LLM？

它是 NVIDIA 生态中的推理优化方案，适合在 NVIDIA 硬件上做深度编译、量化和性能优化，代价是平台绑定和部署复杂度。

### 如何优化 LLM 推理成本？

减少无效 token 和重复调用，使用缓存、模型路由、批处理、量化、蒸馏、上下文压缩和合理输出限制，并用单位成功任务成本评估。

### 什么是 Speculative Decoding？

用小模型生成候选 token，再由大模型批量验证，以提高解码速度。是否有效取决于接受率、模型匹配和验证开销。

### 什么是 Token Budget，如何强制执行？

Token Budget 是一次请求允许使用的输入/输出或推理 token 上限。调用前估算，设置 max tokens，超限前摘要、截断、路由或拒答，并记录实际消耗。

### 如何设计多模型供应商 Fallback？

统一模型网关，记录能力差异，设置超时、熔断、健康检查、重试和备用模型。切换后仍要做质量、格式、成本和数据处理验证。

## 记忆

### 最好的 Agent Memory 框架是什么？

取决于短期状态、长期事实、语义检索、用户画像、权限、过期和删除需求。先定义记忆生命周期，再选择数据库或框架。

### 短期记忆和长期记忆有什么区别？

短期记忆服务当前任务和对话上下文；长期记忆跨会话保存用户或业务事实。长期记忆需要来源、置信度、权限、更新、过期和删除策略。

### 知识图谱如何帮助 Agent？

图谱显式表示实体、关系和约束，帮助 Agent 做多跳查询、关系验证和一致性检查。构建成本和数据更新成本是主要权衡。

## 安全

### 什么是 Prompt Injection？

攻击者通过用户输入、网页、文档或工具结果注入伪指令，诱导模型忽略原有规则、泄露数据或执行危险动作。

### 如何防止 Prompt Injection？

不可信内容与系统指令隔离，工具最小权限，参数和输出校验，沙箱和网络限制，高风险操作人工确认，并通过对抗测试持续验证。

### 什么是 OWASP LLM Top 10？

它总结 LLM 应用常见风险，例如 Prompt Injection、敏感信息泄露、供应链、数据/模型投毒、错误输出、过度代理权限和拒绝服务。它是风险清单，不是完整安全方案。

### 什么是 Agent Sandboxing？

在隔离环境中限制 Agent 的文件、网络、进程、凭据和资源权限，防止模型或工具影响主机和生产系统。沙箱要配合审计、超时、配额和人工确认。
