# 《AI 系统设计面试答题框架》中文概要

## 这篇资料解决什么问题

它解决的是“知道技术，但面试时回答不成体系”的问题。资料提供了系统设计、概念解释、方案比较、故障排查和行为面试五种回答框架。

## 最重要的框架

### SPIDER：系统设计

```text
S 明确范围 → P 确定优先级 → I 初始架构 →
D 深入关键路径 → E 评测与可观测性 → R 可靠性与规模化
```

### ETA：解释概念

```text
先简单解释 → 补充技术细节 → 说明应用和权衡
```

### STAR-L：行为面试

```text
背景 → 任务 → 行动 → 结果 → 学习
```

## 面试中必须主动覆盖的内容

- 需求和非目标
- 延迟、吞吐、成本和质量指标
- 数据流和控制流
- 失败模式、降级和恢复
- 评测、监控和回滚
- 安全、权限和数据隔离
- 自己真实负责的范围

## 与你的经历结合

## 一句话记忆

优秀的 AI 系统设计回答不是“我知道哪些组件”，而是“我如何从目标出发，设计一个可以评测、监控、降级和持续改进的系统”。
